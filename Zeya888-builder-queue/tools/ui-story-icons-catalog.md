Для каждой UI-стори — **обязательный артефакт «каталог иконок/визуалов»** (наравне с таблицей текстов/переводов [[feedback-story-texts-translations]]). Раньше иконки «совсем забывались».

**Что содержит** (таблица, снятая с мокапа этой стори): для каждого функционального визуала —
1. описание контекста использования (в каком состоянии/элементе);
2. **зафиксированное имя файла** (чтобы вёрстка ссылалась на стабильный путь);
3. промпт для генерации в **растре на прозрачном фоне** (thin-line, 256×256, PNG alpha, стиль Lucide/Linear под тёмный DOGEstonia-UI).

**Конвенции проекта (verified):** дом файлов — `public/icons/<story-scope>/`, имя `ic-<kebab>.png`; бренд-жёлтый `#f5c542`/`#f5c518`, нейтраль `#f5f7fa`; бренд-логотип и флаги ET/RU/US уже есть в `public/assets/` — reuse, не генерировать. Scope — только продуктовые иконки состояний, БЕЗ артборд-служебной графики (стрелки, боксы flow/error-панелей, маркеры ✓/✕).

**Образец:** `spa-app/docs/tasks/backlog-stories/identity-auth/STORY-SPA-ID-12-icon-assets.md` (снят с M128). Держать файл рядом со стори + ссылка в самой стори (раздел «Артборд»).

**Why:** визуал-слой выпадал из планирования; фиксация имён заранее убирает рассинхрон вёрстки. **How to apply:** при доработке любой UI-стори с мокапом — идентифицировать все визуалы и оформить такой каталог; ссылку вписать в стори.
