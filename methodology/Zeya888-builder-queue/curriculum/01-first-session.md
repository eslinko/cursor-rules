# Модуль 1 — Первая сессия

## Цель

Запустить Phase 0 onboarding без изменений кода.

## Шаги

1. Скопируйте блок из [`../core/session-starter.md`](../core/session-starter.md) §2 в новый чат Cursor.
2. Укажите `builder_project` и `workspace_root`.
3. Дождитесь **Onboarding summary** и **Ready for: P1|P2|…**.
4. Не переходите к P3, пока оператор не выбрал фазу.

## Проверка

- Агент назвал `focus_root`, `test_command`, active pkg (или объяснил отсутствие)
- Агент **не** менял код в Phase 0
